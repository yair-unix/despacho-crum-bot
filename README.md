# Despacho CRUM Bot V2

Unidades: 674 a 695.

Flujo:
1. Elegir económico.
2. Pulsar Despachar.
3. Pegar enlace de Google Maps.
4. La unidad cambia a rojo En servicio.
5. El enlace queda registrado y puede abrirse con el botón Abrir destino.
6. Finalizar servicio regresa la unidad a verde Disponible.
